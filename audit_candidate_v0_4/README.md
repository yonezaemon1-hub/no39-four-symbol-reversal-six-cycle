# No.39 探索候補 v0.4 — 2026年10月25日

**候補題材：一様な6状態の輪で、時間の向きを4文字の確率差から検出する。**

6か所を時計回り・反時計回りにランダム移動する粒子を考える。
各場所は `001011` と色分けしてあり、観測者には位置ではなく0/1だけが見える。
定常状態から、一定間隔 tau ごとに観測する。

## 今回残した狭い問い

`0011` と逆再生 `1100` の出現確率を比べる。
この1組の4文字列だけで、観測過程に時間反転の差があるかを完全に判定できるか。

内部導出では、モデルの全パラメータについて次の二分が得られた。

| 観測間隔 | 4文字の確率差 | さらに長い列 |
| --- | --- | --- |
| 特定の共鳴間隔以外（時計回り・反時計回りの速さが異なる） | 必ず非ゼロ | 向きを区別できる |
| 共鳴間隔 | ゼロ | すべての長さで時間反転対称 |

3文字以下では定常二値過程の時間反転の差は現れない。したがって、このモデルの
非共鳴の場合は「連続4文字」が最短になる。

ここで「4文字で足りる」は**4文字列の出現確率を使える**という意味。
4ビットを1回読むだけで確実に判定できるという意味ではない。

「非平衡なら何でも4文字で分かる」「一般の隠れマルコフモデルで最小6状態」
という主張は含めていない。対象は一様な輪・固定二値ラベル・定常初期分布・
等間隔観測に限定される。

## 再実行

ZIPを展開し、そのフォルダで次を実行する。

```powershell
python check_hashes.py
python verify.py --output rerun.json
python -I audit_positivity_dense.py --output positivity_rerun.json
```
