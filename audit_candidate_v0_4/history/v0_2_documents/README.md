# No.39 探索候補 v0.2 — 2026年10月25日

**候補題材：一様な6状態の輪で、時間の向きを4文字の確率差から検出する。**

6か所を時計回り・反時計回りにランダム移動する粒子を考える。
各場所は `001011` と色分けしてあり、観測者には位置ではなく0/1だけが見える。
定常状態から、一定間隔 tau ごとに観測する。

## 今回残した狭い問い

`0011` と逆再生 `1100` の出現確率を比べる。
この1組の4文字列だけで、観測過程に時間反転の差があるかを完全に判定できるか。

内部導出では、モデルの全パラメータについて次の二分が得られた。

| 観測間隔 | 4文字の確率差 | さらに長い列 |
| --- | --- | --- |
| 特定の共鳴間隔以外（時計回り・反時計回りの速さが異なる） | 必ず非ゼロ | 向きを区別できる |
| 共鳴間隔 | ゼロ | すべての長さで時間反転対称 |

3文字以下では定常二値過程の時間反転の差は現れない。したがって、このモデルの
非共鳴の場合は「連続4文字」が最短になる。

ここで「4文字で足りる」は**4文字列の出現確率を使える**という意味。
4ビットを1回読むだけで確実に判定できるという意味ではない。

## 既知部分を除いた判定

| 項目 | 状態 |
| --- | --- |
| 3文字以下で差が出ないこと | 既知（Arola-Fernandez--Lacasa 2023） |
| 周期観測で時間の向きが隠れる現象 | 既知の文脈（Bauerほか 2025） |
| 十分長い列なら区別できる条件 | 景色復元の既知定理の帰結（Finucaneほか 2014） |
| 4文字1組で常に足りること・確率差の明示式 | 今回の残差候補、先行未確定 |
| 数式の内部検算 | 完了、PROOF.mdに証明案 |
| 計算 | v0.2の実行結果はevidence_v0_2.json。evidence.jsonはv0.1の記録 |
| 外部数値監査 | 3000点の別実装検算PASSとの報告を受領。原コード・生データは未受領 |
| 証明の別コード検算 | Bernstein係数・平方完成・場合分けなど8項目PASS（内部追加検算） |
| 独立した証明監査 | 未実施 |

「非平衡なら何でも4文字で分かる」「一般の隠れマルコフモデルで最小6状態」
という主張は含めていない。対象は一様な輪・固定二値ラベル・定常初期分布・
等間隔観測に限定される。

## 再実行

ZIPを展開し、そのフォルダで次を実行する。

```powershell
python check_hashes.py
python verify.py --output rerun.json
python -I audit_positivity_dense.py --output positivity_rerun.json
```

`python -I verify.py --output isolated_rerun.json` にも対応した。
Matzinger–Lemberの大学公開前稿を確認した比較はPRIOR_ART.md、
受領した数値監査の範囲はRECEIVED_NUMERICAL_REVIEW.mdに記録した。
証明本文の第1〜5節はv0.1と同一。変更履歴はCHANGES.jsonを参照。

Python 3.10以上の標準ライブラリだけを使用する。ネット接続・有料API・Ollama・
追加パッケージは不要。今回の実行環境はevidence_v0_2.jsonに記録したLinux環境であり、
Windows実機での再実行はまだ行っていない。

`exact_algebra.py` は有理数係数の多項式を使う厳密検算。
`verify.py` は厳密な正値証明の係数検算と、フーリエ法とは別にポアソン跳躍数を
足し上げる実装での数値照合を行う。数値照合は誤差保証付き証明ではなく診断。

先行文献の確認範囲と未確認部分はPRIOR_ART.md、数学の定式化・証明はPROOF.md。
